# 야시장 한입특급 v60 귀여운 UI 적용·검증 리포트 (20260928)v1

## A. 핵심 결론
1. **UI 개선안 1·2차를 적용했습니다(0.19.0 / 웹 v60).** 파스텔 색, 둥근 글꼴(Jua), 말랑하게 눌리는 버튼, 탑승 하트와 출발 반짝이, 눈 달린 차량, 2등신 승객입니다.
2. **게임 규칙과 결과에는 변화가 없습니다.** 원본 테스트 128/128, 200단계 자동 플레이 새치기 거절·수락 모두 200/200, 브라우저 E2E 12/12를 통과했습니다.
3. **색 맞추기 가독성을 지켰습니다.** 승객 옷과 차량의 7색은 그대로 두고 꾸밈 부분만 파스텔로 바꿨습니다. 차량 눈은 방향 화살표보다 먼저 그려서 화살표를 가리지 않습니다.

## B. 데이터 범위 및 정의
- **대상:** 원본 `pickup-rush-color-station`과 배포본 `pickup-rush-play`의 `claude/v60-cute` 브랜치. 비교 기준은 v59(원본 `7cffa76`, 배포 `0c73aec`)입니다.
- **환경:** Node v22.22.2, Playwright 1.56.1(Chromium), 390×844, 배율 2
- **범위 밖:** 3차안(마스코트, 출석 도장판, 스티커 도감), 실기기 확인, Android 빌드

## D. 검증 및 한계
- **가독성:** 맨 앞 승객(1.6배)은 얼굴이 커져서 두 번째 승객과 조금 겹칩니다. 색 고리와 크기로 구분은 됩니다.
- **톤 혼재:** 단계 출발 티켓은 기존 민트 그라데이션을 그대로 뒀습니다. 분홍과 민트가 섞여 보일 수 있습니다.
- **성능:** 저사양 기기에서 프레임은 확인하지 못했습니다. "움직임 줄이기" 설정이 켜져 있으면 하트, 반짝이, 버튼 눌림, 별 등장 효과를 모두 끕니다.
- **검증 방법 한계:** "귀여움"에 대한 반응은 측정하지 않았습니다. 타깃 이용자 선호 테스트를 권합니다.
